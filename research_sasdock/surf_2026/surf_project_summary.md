# surf_project_summary

`surf_2026` is an early-stage protein SAXS/modeling sub-project supporting the larger `sas-assembly` goals.

Focus:
- Build and organize comparative datasets for **thaumatin** and **beta-lactoglobulin (A/B variants)**.
- Use selected SAXS profiles that span likely monomeric and associated/aggregated conditions.
- Develop and test reproducible fitting/modeling workflows (including oligomerization hypotheses) suitable for student-driven summer research.

Current assets:
- Structure/sequence references (PDB + FASTA) for thaumatin and beta-lactoglobulin variants.
- Curated SAXS data files plus notes identifying key conditions (pH, concentration, buffer/salt) and expected behavior.
- Planning docs and meeting notes tying data analysis to an 11-week summer research timeline.

Near-term objective:
- Produce a robust, validated baseline analysis workflow that can distinguish dilute/monomer-like profiles from association/aggregation cases before expanding to broader mechanistic modeling.
